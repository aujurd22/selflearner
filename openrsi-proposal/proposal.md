| Evaluation | Fixed evaluation protocol | **Budget: 200 proposer dispatch attempts per loop, enforced at the TRANSPORT LAYER: `budget.consume()` is invoked inside `llm_client.ask` and `propose_check.ask_effort` immediately before every `urlopen`, so each attempt that leaves the runner counts one unit — 429 backoff retries and post-dispatch transport failures included; there is no wrapper the agent can route around, and `budget.py` also raises `BudgetExhausted` BEFORE dispatch when the cap is reached.** The counter is PERSISTENT (`runs/budget_state.json`, atomic rewrite on every unit): a resume restores the cumulative count, it is never reset by restart; zeroing requires an explicit `run_overnight.py budget-reset` invocation, which itself is logged. **The loop terminates when the budget is exhausted (or the wall-clock deadline passes) — there is no round count in the protocol**, so "stopped at N rounds with budget remaining" cannot occur by construction; `FLYLOOP_ROUND_CAP` exists only as an explicit emergency override and is not used in the formal runs. Aggregation: each loop produces ONE scored snapshot; the loop's score is its primary count; the formal result is the median of the >=3 per-loop scores per arm (zero-valid snapshots are VALID results: score 0, included in the median — zero-yield loops are explicitly anticipated and are not unscored). INFRA semantics: a snapshot whose compile stage cannot launch (isolation probe failed, toolchain missing) is INFRA — unscored, not budget-consumed, and EXCLUDED from all secondary rates; a snapshot that parses but yields zero passing lemmas = valid score-0 result. ## CHANGELOG (v10 — responses to the 2026-10-07 07:22 review)

1. **Budget enforcement rewritten at the transport layer** (Metric +
   Readiness fails): the old design wrapped `ask_effort` with a
   counter, so internal 429 retries were invisible, a resume reset
   the counter, and a 20-round cap could stop the run with budget
   remaining. Now: `budget.py` is a persistent transport-layer
   counter invoked inside both API helpers immediately before every
   `urlopen` (every dispatch attempt counts; `BudgetExhausted` raised
   BEFORE dispatch at the cap); state survives restarts in
   `runs/budget_state.json` (atomic rewrite per unit); the protocol
   has NO round cap — the loop runs to budget exhaustion.
2. **Evaluation integrity: scorer now matches the declared contract**
   (Eval Integrity fail): `unshare -rn` availability is probed at
   import; probe failure raises InfraError (whole snapshot INFRA,
   unscored) instead of silently falling back to unisolated
   compilation; task.toml now declares legal per-phase allowlists
   (`[agent]`: ARK only; `[verifier]`: DeepSeek only; baseline
   no-network) instead of the previously invalid `full-network` value
   and full-network Judge; within-snapshot dedup now strips binder
   names (alpha-renaming invariant) and every NOVEL lemma is
   re-adjudicated against earlier NOVEL lemmas of the same snapshot;
   INFRA entries are excluded from all secondary rates; the Judge
   writes the Harbor reward file `/logs/verifier/reward.json`.
3. **Task readiness: platform-required artifacts added** (Readiness
   fail): `tests/test.sh` (the verifier entry the harness executes),
   `environment/Dockerfile` + `environment/docker-compose.yaml` (the
   previously missing environment definition), credential injection
   via `[agent.env]`/`[verifier.env]` host-secret templates, and
   `judge_client.py`'s functionality inlined into judge_score.py
   (the import previously pointed at a module not present in the
   repository).
4. **Repository bundle fetch bug fixed**: the pinned ref was wrapped
   in Markdown bold markers (`**fdca4fc**`); the review bot's bundle
   request embedded the trailing asterisks and every review this day
   started from a fetch-error bundle. The pin is now a bare full
   SHA. Runs logs (`runs/overnight_20261005/`) are committed so the
   pinned tree contains every artifact the proposal cites.
5. **Compute note rewritten**: no per-loop rounds-per-loop conversion
   is claimed; the loop is budget-bounded, the per-loop wall-clock
   range and its bound are stated, and measured per-loop dispatch
   counts replace the estimate.
